# Screenshot Evidence

This folder intentionally keeps only the strongest visual evidence for the portfolio version of the project.

- `hmi-overview.png` — process context and live HMI values.
- `fc03-register-snapshot.png` — passive FC03 register polling and process-value correlation.
- `outlet-flow-sp-r16-201.png` — controlled setpoint change mapped to Register 16 with FC06.
- `inlet-valve-open-r3-100.png` — controlled valve command mapped to Register 3 = 100.
- `outlet-valve-stop-r27-1.png` — separate stop/hold command mapped to Register 27 = 1.

The omitted screenshots were valid but redundant examples of the same mapping methodology. Keeping the evidence set small makes the repository easier to review.
