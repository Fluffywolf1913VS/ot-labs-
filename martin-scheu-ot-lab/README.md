# Martin Scheu OT Lab — Security Project Series

This directory contains a series of OT/ICS security projects built around **Martin Scheu's `ot-lab` framework**.

## Original Project

- Author: **Martin Scheu**
- Project: `ot-lab`
- Source: `https://gitlab.switch.ch/martin.scheu/ot-lab`
- License: **MIT**

The underlying lab framework is not my work.

My contributions in this directory focus on:

- deployment and validation
- packet analysis
- Modbus register mapping
- OT baselining
- detection engineering
- firewall hardening
- network segmentation
- security monitoring
- incident-response exercises
- process-aware security analysis

Each subdirectory represents a separate hands-on project using the lab as the technical foundation.
